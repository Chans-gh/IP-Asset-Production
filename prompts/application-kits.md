# 10 个应用成品套装 · 参数化 Prompt

> 模板来源：SPEC-005 v0.1 草案；此文件为设计模板，不代表某个 Provider 已具有特定原生尺寸/透明/可印刷文件能力。使用前必须拼入 COMMON-LOCK、COMMON-OUTPUT，并检查变量。
的应用成品模板（APP-01 ～ APP-10）

**统一原则**：必须交付可用的单项文件，而不是仅生成预览大拼图；所有准确文字由排版层负责。品牌 Logo/标识只能使用用户提供且允许使用的素材。应用成品应有版本、角色基准、用途、画幅、格式与生产批次信息。

| 编号 | 套装 | 默认交付（通用参考，并非任何平台的官方发布规范） | 应用范围 |

### APP-01 表情包 Prompt

```text
使用 COMMON-LOCK。为 {{IP_ID}} 生成 {{EMOJI_COUNT}} 个独立社交表情，每个表达一个清楚的聊天语义：{{EMOJI_MEANINGS}}。构图一律是大头贴式胸像：只画头部到胸口，不画全身，脸部占画面高度约一半，手势可抬到脸旁入画。表情夸张程度由 {{STYLE_PROFILE}} 决定：写实数字人保持自然表情；二维/三维卡通可以按已确定风格适度夸张。角色轮廓、识别特征和主体比例统一；图形边缘清晰、构图完整、背景透明、周围预留至少 8% 安全留白。每 8 个一张 4:3 透明背景设定图（2 行 × 4 列等分网格）一次生成，由程序切分为独立 1024×1024 RGBA PNG；需要文字的表情在视觉图外用排版程序叠加 {{EXACT_TEXT_MAP}}。另交付统一预览总览，不以总览代替独立表情文件。
```

### APP-02 会议室门牌包 Prompt

```text
使用 COMMON-LOCK。围绕 {{IP_ID}} 创作统一风格的会议室门牌插画系列，文案状态包括 {{SIGN_STATES}}，会议室名称={{ROOM_NAME}}。每个状态配一幅角色状态插画，全部状态整组一次生成一张透明无缝网格设定图再由程序切分：会议中=安静专注并具有会议元素；空闲=轻松欢迎；请勿打扰=手势/表情明确且礼貌；欢迎使用=友好引导。保持 IP 形象与主色一致，插画仅占门牌右侧或左侧约 30%–40%，另一侧预留完整文字区，不让生图模型直接生成中文字。默认物理成品 300×120 mm，四周 3 mm 出血，内容安全边距不小于 8 mm；排版层输入准确文案、品牌色、房间名称，导出 300ppi 印刷 PDF 和 PNG 预览。门牌每状态独立交付。
```

### APP-03 办公导视包 Prompt

```text
使用 COMMON-LOCK。制作 {{SIGN_LOCATIONS}} 办公空间导视插画套装，每个地点配一个与其功能相符的角色动作/道具。人物或卡通对象的风格与轮廓保持一致，标识图形易远距离识别，留出大面积准确文字和箭头区域。全部地点的角色插画整组一次生成一张透明无缝网格设定图并由程序切分，再交由排版层按照空间尺寸 {{PHYSICAL_SIZE_MM}}、语言 {{LANGUAGE}}、导向 {{ARROW_DIRECTION}} 制作可打印门牌 PDF；文字不得嵌入由模型随机生成的背景。
```

### APP-04 社交头像与封面包 Prompt

```text
使用 COMMON-LOCK。生成账号统一视觉包：1）正面可辨识头像，面部/主体轮廓占主要视域，1024×1024 PNG；2）通用社交横幅宽屏背景 2560×1440 PNG，保留中央重要内容安全区并适应平台裁切；3）竖版封面 1080×1920 PNG，预留标题区域。背景、光照、造型形成统一品牌语言；准确名称和标题由排版层加入。平台具体裁切安全区须使用已配置的渠道模板复核。
```

### APP-05 视频贴片与直播组件 Prompt

```text
使用 COMMON-LOCK。设计 {{IP_ID}} 的直播/视频角色贴片系列，包括欢迎、点赞、关注、提示、结束等状态；角色与动态标签预留区分离。全部状态整组一次生成一张透明无缝网格设定图，由程序切分为独立透明 PNG（长边 2048 px），同时生成横向 3840×2160 和纵向 2160×3840 的安全布局预览。字幕和口播提示文案通过可编辑字幕/排版层加入。需要真实运动的版本交给动画模块处理，不把静态图宣称为动态文件。
```

### APP-06 节日主题海报包 Prompt

```text
使用 COMMON-LOCK。根据节日={{HOLIDAY}}、活动主题={{CAMPAIGN}}、品牌色={{BRAND_COLORS}} 为 {{IP_ID}} 生成视觉系列，角色占据画面的可识别位置，允许按节日更换已批准的服装/配饰，不得改变身份。设计背景、节日元素和清晰的标题留白区域，分别交付正方形 2048×2048、4:5 2160×2700、9:16 2160×3840。排版层准确加入 {{HEADLINE}}、{{SUBTEXT}}、日期与行动信息。
```

### APP-07 主题壁纸包 Prompt

```text
使用 COMMON-LOCK。制作桌面及手机双规格壁纸，保证中心角色完整且适合对应界面覆盖：桌面 3840×2160、手机 2160×3840。主体与背景具有视觉层次，但不遮挡常用图标区域，风格与角色设定一致。分别适配宽屏与窄屏构图，禁止简单拉伸裁剪导致头部/尾巴等重要部位缺失。交付独立 PNG/JPEG。
```

### APP-08 打印贴纸与周边包 Prompt

```text
使用 COMMON-LOCK。将 {{IP_ID}} 生成 {{STICKER_VARIANTS}} 个角色贴纸插画，统一外轮廓留白及颜色，避免细小无法印制的部件；全部贴纸整组一次生成一张透明无缝网格设定图，由程序切分。输出各自透明 3000×3000 PNG 母版，同时提供裁切轮廓建议路径。若需实体印刷，由排版程序为指定物理尺寸 {{PRINT_SIZE_MM}} 生成 300ppi、3 mm 出血、印厂指定色彩配置的可印刷 PDF；不得只提供白底预览图片。
```

### APP-09 欢迎/提示牌包 Prompt

```text
使用 COMMON-LOCK。为 {{IP_ID}} 设计统一系列的功能提示插画：{{NOTICE_TEXTS}}。每条信息用不同但风格一致的表情与姿态呈现，全部插画整组一次生成一张透明无缝网格设定图并由程序切分；背景简洁、符号语义明确、长距离阅读对比度高。根据目标载体输出横版、竖版或立式标牌，角色插画和文字层分离；排版程序添加逐字准确的文案并按物理尺寸、出血和安全边距导出。
```

### APP-10 角色介绍与品牌应用包 Prompt

```text
使用 COMMON-LOCK。基于已确认角色资料 {{IP_PROFILE}} 生成 IP 介绍、性格、代表动作、标准造型、品牌配色、使用场景等页面的视觉素材。角色图与内容模块独立，保持统一版式和可编辑性；中文名称、角色描述、品牌信息必须从批准的数据源加载并在排版层处理。输出屏幕版 1920×1080/2560×1440 与必要的打印版 PDF；不要把未经用户确认的虚构人设当作事实。
```
